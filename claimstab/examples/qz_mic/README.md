# QZ grassland case study

This example converts the current paper-2 endpoint results into the four-component
framework.

## Files

- `claims.csv`: 14 claim definitions covering beta composition, alpha diversity,
  natural-reference ranking, LEfSe reproducibility and absolute abundance.
- `reconstruction.csv`: 16S/ITS phylum and alpha reconstruction checks plus two
  unavailable data layers.
- `endpoints.csv`: results from original OTU, current ASV-phylum, current ASV,
  15-sample and 18-sample analyses.
- `output/`: matrices generated by `claimstab`.

## Rebuild inputs

```bash
python build_inputs.py
```

This adapter is specific to the QZ project. The generic package itself only
needs the three input CSV files.

## Run the framework

```bash
python -m claimstab build \
  --claims claims.csv \
  --reconstruction reconstruction.csv \
  --endpoints endpoints.csv \
  --output-dir output \
  --alpha 0.05
```

## Interpretation

- 16S phylum reconstruction is classified as stable.
- ITS phylum reconstruction is partial because of the classification-sensitive
  As sample.
- Alpha reconstruction is partial because cross-pipeline sample-rank
  correlations are not uniformly high.
- LEfSe and absolute abundance are not verifiable because required inputs are
  absent.
- The AEFP natural-reference claim is descriptive rather than confirmed because
  significance support is absent.

The output is an audit aid. The paper should retain its manually reviewed
claim-level interpretation.
